# PokéScrape Analytics Application

## Overview 
Your source for Pokémon market data and statistics. Scraped and analyzed in real-time.

## Tech Stack
- Java 17+
- Spring Boot 3.x
- PostgreSQL
- AWS S3 (file storage)
- JWT Authentication
- OAuth2 Authentication
- Maven

## Prerequisites
Java 17 or higher
PostgreSQL installed and running
Maven
Git
AWS account (for file storage)
